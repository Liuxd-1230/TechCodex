    第二版验收与样章对照¶

    本轮范围：先完成第 3 章源跟随器教学样章，再重构第 2、3 章与在线阅读站。第 4～10 章仍未成稿。本记录是编辑与技术检查，不是读者学习效果研究。

    教学自检¶

    检查问题 第二版对应内容
    读者先知道要解决什么吗？ 样章从高阻前级被负载拉动进入，先说明缓冲的用途，再计算增益
    公式是否跟随电路变化出现？ 从 VGS=VI−VO、输出电流平衡到受控源测试，再转换为戴维南等效
    一个方法能否迁移？ 同样的源端测试连接到共栅输入阻抗；源极退化连接到共源共栅输出电阻
    近似的失效条件是否可见？ 共栅 Rin 随漏端负载变化；共源共栅高阻抗未必改善低阻负载增益
    正文是否又被实验支配？ 保留一个真实 CS 加载反例；完整参数、CSV、误差和频响放入实验档案
    知识体系是否拓宽？ 第 2 章补入结构、电荷积分、二阶效应和电容；第 3 章覆盖主要单级拓扑及负载形式

    旧版保留在 器件档案、共源级档案 和 Git 历史中。新版不能仅因排版更好就视为教学改善；本次自评依据的是新增解释链、端口方法与可迁移的反例，尚无独立读者测试。

    数学与图示核查¶

    样章解析例子的输出电阻与三个加载增益已核对。使用独立的 MOS 节点导纳盖章法，对源跟随器、共栅、源极退化和共源共栅公式作代数交叉检查，脚本是 check_teaching.py。这些解析检查不冒充工艺仿真数据。

    原理图使用明确区分 D/G/S/B 的四端符号、体结箭头及独立体连接；青色箭头只表示扰动。器件截面与电容图为概念图，标明未按真实工艺比例绘制、不能替代完整 BSIM 电荷模型。图源保存在 生成脚本 与 矢量绘图模块。

    第七阶段：噪声与交互教材（2026-10-23）¶

    教材与工程结果¶

    新增第7章的章节导航及六篇正文，对照第二版 §7.1–7.10：统计特性、PSD/ASD、器件与端口表示、四种单级拓扑、镜像与差分、噪声带宽、输入参考积分、功耗/面积设计和相关性矩阵。正文独立推导，三个新噪声路径 SVG 和三组科学图均保留生成源；模型细节、原始 CSV 与失败候选留在实验资源。

    真实 Windows ngspice47 .noise 沿用第5/6章 OTA 基线。100Hz–100kHz 输入参考噪声由28.25µV RMS降至面积方案2.59µV，后者功耗0.394mW、增益335.4V/V、3dB带宽276.2kHz。保持先写下的4µV/0.45mW/150V/V/100kHz指标，原基准和电流翻倍等失败方案完整保留。输入与PMOS栅面积各约增加100倍，不能称为版图最优或量产合格。

    数学、仿真与代码检查¶

    • 电阻RC校准单边系数、PSD/ASD与积分单位；逐点验证输出PSD除以实际增益模平方等于输入PSD；器件分组总和与总谱一致；独立幂律积分与ngspice全扫描积分一致到0.3%以内。
    • check_noise.py 核验白噪声、1/f、RC积分以及150组独立器件端子电流/共栅/共源共栅/复协方差算例，检查全部噪声预算与哈希。JS检查解析积分、601个原始工艺样本、滑块频带范围和禁止外推。
    • 原 run.py、run_differential.py、run_mirrors.py、run_frequency.py 四套仿真入口在初始HEAD的隔离副本中以原生模拟器重跑通过；当前仓库旧实验记录未被重写。第2–6章独立节点方程和三个旧交互的数值检查也通过。
    • 严格构建通过；57个HTML、逾5300条本地资源/锚点引用、自托管25个MathJax文件、SVG/XML与模型/数据源哈希检查通过。网页数据导出仅需Python标准库，站点环境不因它增加NumPy依赖。

    按 ponytail-review 检查了计算模块、DOM调用、数据导出、构建钩子和实际调用链。浏览器发现的频带动画终点浮点越界已通过限定采样域和精确结束状态修复，再测试快速反复Home/End没有新增脚本错误。没有用放宽仿真结果门限让设计合格。

    实际浏览器与视觉终审¶

    桌面1440×1000、平板820×1180、手机390×844，以及默认窗口661×849均检查并截图。首页由平铺目录变为教材章节导览；阅读页面统一书脊位置、纸面/页边、字体层级、图注、表格、深入推导和阅读进度。技术图可打开原SVG；关键资源URL带内容哈希，避免新版HTML配到旧CSS。

    新噪声交互将上方对数ASD与下方线性的每十倍频程方差对应，只有下图面积表示方差。解析源和固定GF180预计算源分别标明；没有工艺自由缩放或实时SPICE宣称。频带过渡180ms、可中断，每帧用同一组显示边界计算曲线区域和RMS；减少动态效果时即时更新，源切换不混合不同模型。

    实际操作频谱切换、方向键/Home/End、防止上下限交叉、连续中断和减少动态效果。全文搜索“噪声”得到30项结果并成功跳转正文；旧差分转向、镜像顺从电压和米勒交互均操作成功。新页面公式无MathJax错误、图片加载正常，没有整页横向溢出。禁用脚本保留正文、静态图和LaTex公式源；阻断JSON显示回退提示；打印保留静态图与已渲染公式，隐藏交互。
