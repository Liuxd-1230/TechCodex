    首批内容验证记录¶

    日期：2026-10-21。范围为器件篇与第 3 章的共源级专题，完整第 2～10 章尚未完成。

    数值与物理检查¶

    Windows x86-64 原生 ngspice 47 实际完成 19 个网表：3 个长度的转移扫描、4 条输出特性、1 个体偏置扫描、9 个工艺角/温度组合的双极性器件冒烟测试、2 个共源级版本。每个共源级版本都执行 OP、DC 微扰、AC 和 TRAN。

    检查 实际结果
    上游模型 SHA-256 与固定提交清单一致；原文件未修改
    数据有限性、转移电流单调性 通过
    三种长度 gm 与栅压中心差分 相差小于 1%
    主器件 gds 与漏压中心差分 相差小于 1%
    固定 VGS/VDS 的体偏置测试 阈值随 VSB 增大而上升
    NMOS/PMOS × typical/ff/ss × −40/27/125 °C 均成功偏置并输出非零电流；仅为兼容性测试
    共源级工作点 两版电流为正，模型 VDSAT 低于实际 VDS
    KCL/AC/DC 增益 两版均相差小于 0.3%
    RS=0 基准 Vout=1.71297 V，ID=40.693 µA，AC 增益 −11.8342，−3 dB 频率约 2.097 MHz
    RS=1 kΩ 基准 Vout=2.15571 V，ID=29.336 µA，AC 增益 −7.3708

    测量定义、模板展开方式与收敛容差见 实验说明 和源文件。完整版本、模型/网表/数据哈希、执行时间与检查列表保存在 run.json。原始运行日志留在本地 build/，重新运行即可获得，不上传含本地执行细节的缓存。

    检查过程中曾有一次 ngspice 子进程返回非零且没有输出文本，运行器当即报错；直接重跑该网表和完整实验均通过，原因尚未定位。没有加入自动重试掩盖问题。日志现在显式保存退出码，后续若再现可据此排查原生程序或运行环境。

    图形检查¶

    5 张数据图均来自提交的 CSV。输出特性与本征增益图在首次视觉检查后缩小无用纵轴留白；转移特性纵轴覆盖完整最低电流，没有悄悄裁掉弱反型数据。

    编辑阶段使用 pe-plots-paper 的三通道审查：600 dpi、3.5 英寸宽度与边距检查；实际 IEEEtran 双栏页面编译；逐图视觉检查。页面模板仅作字号与排版校准，不属于教材正文，也不上传到仓库。

    审查收据：RESULT: PASS；LINTS: 0。单栏宽度下，图中文字比正文小且能清楚阅读，接近 8 pt 图注的大小。

    视觉项目 结果
    文字/曲线重叠 通过；参数标注在曲线右侧，Bode 图例位于空白处
    字号统一 通过；曲线标签与坐标文字一致，图例为次级字号
    留白与裁切 通过；曲线均在显示范围内，未裁切标签
    灰度可辨性 通过；理论为虚线，曲线家族有直接参数标注
    轴标签归属 通过；每幅/每子图有对应量与单位
    信息密度 通过；无装饰标题、重复数值标注
    轴与刻度 通过；频率/电流对数坐标按物理量使用，其余主要刻度为 1/2/5 步进
    图型习惯 通过；静态特性采用宽面板，Bode 共用对数频率轴
    不确定度 仿真非测量，没有捏造误差棒；不表达模型/硅片不确定度
    字体、背景与标题 通过；衬线字体、白底，结论放正文图注

    3 张原创原理图另检查节点、电阻/电容数值、小信号电流方向与网表对应。SVG 做 XML 解析检查，Markdown 本地链接与公式/代码块分隔符由 check_repo.py 检查。

    结论边界¶

    本次没有声称完成整套教材、全 PVT 放大器规格、失配统计、噪声、失真或流片验证。瞬态已运行并保留数据，但尚未建立 THD 或最大线性摆幅测量。后续差分对、电流镜、反馈、运放与稳定性实验按 路线 推进。

    没有下载或公开商业工艺文件；模型文件为公开上游的 Apache-2.0 内容。本地二进制、虚拟环境、压缩包、日志和个人配置均由 Git 忽略。

    干净检出与发布核对¶

    在一个新的 Git 克隆中，先检查已提交模型、网表与数据哈希，再创建新的 Python 3.13 虚拟环境，按完整依赖快照安装。将已核验的官方压缩包作为下载缓存交给 bootstrap.py，由它重新校验并解压安装 ngspice；克隆中没有预先存在的 .tools。

    完整运行 run.py --check、默认独立绘图样式、原理图生成与仓库检查均通过。12 份 CSV 与 metrics.json 共 13 份数值文件，与原始提交逐字节一致；运行时间记录自然不同。默认样式与编辑阶段的 eeplot 样式存在已说明的排版差异，不影响数值。
