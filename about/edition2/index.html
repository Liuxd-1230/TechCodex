    TECHCODEX / 模拟 CMOS从零开始的模电生活

    第二版：让问题带着知识向前走¶

    第一版的主要欠缺是讲授范围被已有实验决定：读者先遇到一组工艺参数，再看到共源级的局部验证，尚未获得分析其他拓扑的方法。第二版把教材知识作为主体；电路演化负责串联，实验只在能检验一个判断时出现。

    读过哪些教学参考¶

    2026-10-21，经正常浏览器访问下列公开文章。普通网页检索接口返回 403，浏览器可显示正文；没有登录、复制原图或使用未公开内容。

    模集王小桃的文章 观察到的讲解方法 在本项目的落实
    戴维南与诺顿等效：两个误解 用端口等效的边界提出问题，再依据负载选择表示方式 样章用同一源跟随器分别解释开路电压、输出电阻和带载增益；明确等效不保留内部功耗
    CS、CG、SF 的小信号分析 先解释电压变化如何沿电路传播，再逐步增加非理想项 每个结构从输入扰动的方向进入；保留体跨导和有限输出电阻的条件
    共源共栅的小信号分析 把新结构化回已经掌握的阻抗问题 从输出测试源推导阻抗提升，再讨论负载是否允许兑现这个提升
    电路直觉的思考 将抽象的频率特性联系到具体信号路径与阻抗变化 第 2 章先建立端口电荷和电流路径，频率分析留出明确接口
    环路稳定性与频率补偿 用时域异常引出频域条件，再解释补偿为何有效 后续第 10 章从阶跃现象引出环路测量，不能仅凭一个相位裕度数字下结论

    这里借鉴组织方法，文字、数值例子与示意图均独立完成。技术参考也需要核验：例如右半平面实零点是 \(s\) 平面上的根，不能解读为在某个实频率 \(j\omega\) 上输出必然为零；共栅的电压增益与电流增益不能混称；等效成立的端口条件必须先写明。

    样章的判断标准¶

    选取第 3 章源跟随器作为样章。读者应能解释：为何单位增益以下的级仍能改善带载结果；为何“输出等于输入减一个 VGS”没有证明增量增益为一；为何关掉输入后仍要保留受控源；为何体接地会让空载增益也小于一；为何电流源负载改善一项限制但不会自动消除体效应。

    先完成样章和网页，检查推导、图的端口与手机布局；再扩展到其余内容。验收基于这些可迁移的问题，而非图数、公式数或仿真数。样章不加入新工艺扫描，数值例子标为解析例子。

    旧版与新版怎样比较¶

    观察点 第一版 第二版应有的变化
    读者首先看到什么 工艺工作点和仿真结论 一个需要解释的电路行为与明确的端口
    对新结构的准备 主要掌握 CS 的增益 掌握测试源、等效电路、加载与受控源处理
    图的作用 核对网表、展示曲线 直接标明输入/输出位置、扰动方向、体端和负载
    非理想因素 作为仿真误差解释 在结论失效处引入，并重新解读设计选择
    实验位置 频繁进入讲授主线 正文少量有意义的对照，完整数据移入实验阅读路径

    这是一份编辑自评，并非学生学习效果研究。没有真实读者测验时，不宣称已经实证提高了学习成绩。

    样章先完成端口与符号复核，KCL 与戴维南路径得到相同增益，解析例子的 820 Ω、0.820、0.758、0.450 经独立数值代入检查。桌面和手机原型审查发现 SVG 公式组件的显示留白，改用自托管 CHTML 与本地字体后，独立公式恢复显示；同时修正两处图中文字与导线的距离。随后才把讲授方式应用到其余第 3 章与第 2 章内容。最终整站检查另记于 第二版验收。

    阅读站方案¶

    比较了 MkDocs 的 Markdown 构建方式、Material 的数学支持 与 Sphinx Book Theme。当前内容以原创 Markdown 讲授为主，不需要笔记本执行或 API 文档生成，因此选用 MkDocs + Material，保留普通链接、图片和美元符号数学。

    排版采用白色正文与浅蓝灰导航，深蓝墨色、少量青绿标注；章标题用系统宋体类衬线字，正文用系统无衬线字。正文约 42 个汉字宽，图注与推导保持同一阅读轴。网站只把已有图与图注组织成 figure，不要求作者写专用短代码。边栏服务章节与节内导航，技术附录用原生 details，手机上折叠侧栏，长公式局部横向滚动。
