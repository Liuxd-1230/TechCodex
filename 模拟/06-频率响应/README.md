# 第 6 章 · 增益还在，信号却跟不上了

第 5 章的五管 OTA 在静态点附近能把差分输入放大约 206 倍。现在让输入变化得越来越快：电流仍由跨导产生，却不再全部用于改变电阻上的电压。一部分必须不断给电容充放电，节点也来不及保持原来的电压关系。

本章要建立的能力是：看到一只放大器，先找信号经过哪些节点、哪些电容跨接不同的电压，再判断带宽可能受什么限制。Bode 图是这些动态关系的一种记录方式。

## 本章的共同约定

小信号量用小写；$s=\sigma+j\omega$，正弦稳态代入 $s=j2\pi f$。除非另说，电源和理想偏置电压交流接地，体端按原理图连接，受控源保留。$C_{gd}$ 等正值二端电容是讲解用的简化模型；真实 BSIM 电荷偏导矩阵可能不对称，不强行化成同一套互易电容。

单级的增益端口逐节说明。OTA 统一取 $v_{id}=v_{i1}-v_{i2}$、$v_{i1}=+v_{id}/2$、$v_{i2}=-v_{id}/2$，输出取右侧 $v_o$，因而低频增益为正。理想输入源的 `AC 1` 表示归一化线性激励，不是让实际 OTA 输入 1 V 振幅。

**开环 −3 dB 带宽、单位增益频率和闭环带宽是三个不同定义。** 本章不把开环相位曲线当作已验证的反馈相位裕度；闭环加载、返回比与补偿留到第 8、10 章。
