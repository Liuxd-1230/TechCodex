# 符号、层次和实验条件

[系列首页](README.md) · [器件篇](02-MOS器件.md) · [共源级](03-共源级.md)

直流工作点用大写量 $I_D,V_{GS},V_{DS}$，围绕该点的小信号用 $i_d,v_{gs},v_{ds}$。总瞬时量可写作 $v_{GS}(t)=V_{GS}+v_{gs}(t)$。下标大小写用于区分工作点和扰动，不用于区别 NMOS/PMOS。

NMOS 漏极电流以流入漏极为正，$V_{GS}=V_G-V_S$、$V_{DS}=V_D-V_S$。体效应公式使用 $V_{SB}=V_S-V_B$；小信号模型使用 $v_{bs}=v_b-v_s$，所以在固定栅、漏电压时，提高源电压会通过 gm、gmb 同时减小漏极电流。ngspice 读出的 PMOS `id` 可能按内部幅值给出，不能据此猜测外部电源电流方向。

| 量 | 定义与单位 |
|---|---|
| $g_m$ | 固定漏源与体偏置时，$\partial I_D/\partial V_{GS}$，S |
| $g_{ds}$ | 固定栅源与体偏置时，$\partial I_D/\partial V_{DS}$，S |
| $g_{mb}$ | $\partial I_D/\partial V_{BS}$，S；本项目用 ngspice 的 `gmbs` |
| $r_o$ | 低频局部输出电阻 $1/g_{ds}$，Ω |
| $A_{v0}$ | 指定负载下的低频电压增益，V/V；反相时为负 |
| $g_m/g_{ds}$ | 单管本征增益的幅值，无量纲 |
| $g_m/I_D$ | 跨导效率，V⁻¹；它本身不是带宽或增益 |
| $V_{OV}$ | 长沟道近似下的 $V_{GS}-V_{TH}$，V |
| $f$、$\omega$ | 频率 Hz 与角频率 rad/s，$\omega=2\pi f$ |

正文会区分三种证据：物理/解析模型用于解释机制；小信号模型用于工作点附近的局部预测；GF180MCU 模型仿真用于检查该组器件、尺寸和条件下的行为。模型仿真不等于硅片测量。

默认条件：GF180MCU `nmos_3p3`，typical，27 °C，随机全局变化和失配关闭，W=10 µm，L=1 µm。器件独立测试取 VDS=1.65 V；共源级的 VDS 由电路求解。除 PVT 冒烟测试外，结面积 AD=AS=5 µm²、周长 PD=PS=21 µm，作为明确的原理图级几何假设；并非从版图提取。网表中写 `ad=5p` 是 5×10⁻¹² m²，`pd=21u` 是 21×10⁻⁶ m。

电阻、电容和电压源是理想测试元件，MOS 是真实工艺紧凑模型。未建模互连、焊盘、封装、版图相关效应和器件失配。PVT 测试仅检查模型可执行性，尚未对放大器进行跨 PVT 规格验收。
