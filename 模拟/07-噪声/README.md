# 第 7 章：听见电路里没有输入的声音

把示波器接到一个偏置正常、输入接地的放大器上，输出仍会抖动。换一台更好的仪器，它不会完全消失。电阻中的载流子在热运动，MOS 沟道的电流在涨落，界面缺陷也会改变导电状态。电源安静、版图对称、公式正确，都不能让这些过程停止。

设计者能做的，是判断哪些涨落会到达输出，以及它们落在多大的观察频带内。上一章我们用带宽描述电路能传递多快的信号；这一章，同一条传递函数还要回答：它放进来了多少噪声？

## 先给随机量一个可设计的尺度

不必预测下一微秒的噪声电压，才能判断电路是否够安静。一个传感器给出 100 µV RMS 的信号，如果输入参考噪声是 28 µV RMS，信号与噪声的功率比只有约 12.5；降到 2.6 µV 后，这个比值约为 1 490。这里比较的频带、信号定义和输入端口必须相同。

这两个噪声数值来自本章同一个 GF180MCU OTA 的不同尺寸方案。先不要寻找“低噪声尺寸公式”。我们先建立从随机过程到器件、从器件到电路、从电路到积分预算的分析方法，再回来解释这个差别。

## 三种模型，各自回答一个问题

本章的白噪声、长沟道沟道噪声和单极点模型用于推导。它们让我们看清参数之间的关系，不能代替实际器件。

真实电路沿用第 5、6 章的五管 OTA，外加尾电流镜参考支路；采用固定版本的 GF180MCU 3.3 V MOS 模型，在 Windows 原生 ngspice 47 中执行小信号 `.noise`。工艺数据、理论计算和交互动画分别标注来源。`.noise` 给出统计频谱，并没有生成一段真实的随机瞬态波形。

> 阅读时反复确认三个量：**观察哪个端口、采用哪种谱密度、积分哪段频带。** 少写其中一个，数值即使算对，也可能回答了另一个问题。

实验的全量工作点、网表、CSV 和校验记录放在[噪声实验资源](../实验/噪声/README.md)。正文只在数据能够澄清一个判断时使用它。
