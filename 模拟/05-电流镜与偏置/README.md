# 第 5 章 · 电流镜与偏置：给电路一份能兑现的电流

第 4 章把尾电流当作已知条件。现在需要回答它从哪里来，以及尾节点移动时，电流源还能不能兑现原来的承诺。与此同时，差分对的两个电流不必再各自流过一只电阻：电流镜可以把左支路的变化送到右边，让两边的信号共同推动一个输出。

本章沿拉扎维第二版第 5 章的四条主线展开：Basic Current Mirrors、Cascode Current Mirrors、Active Current Mirrors、Biasing Techniques。镜像有源负载和五管 OTA 属于第三条线，不只是偏置电流复制的附带应用。

这里有两个事先给定的设计任务：在 3.3 V 下提供 40 µA、在 0.4–2.6 V 输出窗口内误差不超过 5% 的电流镜；以及把 40 µA 参考变成约 80 µA 尾电流，构建有真实偏置网络的五管 OTA 核心。它们贯穿不同专题，但不会替代对其他重要结构的讲解。

正文只保留能解释选择的结果。全尺寸、网表、原始数据、条件和回归在 [实验资源](../实验/电流镜/README.md)。本章真实电路使用 GF180MCU；平方律只用来解释机制和作初步估算。统计失配、完整 PVT 保证、版图寄生、噪声和补偿留待相应章节，不用 nominal 仿真替代它们。
