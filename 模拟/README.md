# 从零开始的模电生活

基于拉扎维《模拟 CMOS 集成电路设计》第二版的理解、推导与实验笔记。

学会一个公式以后，还需要知道它在电路中解释什么。如果更换输入端口、改变负载或让源极浮动，原来的公式为什么失效，又应该怎样重新分析？这套笔记把这种可以迁移的分析能力作为阅读目标。

主线为原书第 2～10 章，文字、推导和图示独立组织。需要基本电路分析、复数与微积分；不要求先配置 PDK。
