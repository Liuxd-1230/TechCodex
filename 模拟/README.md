# 从零开始的模电生活

基于拉扎维《模拟 CMOS 集成电路设计》的理解、推导与实验笔记。

我们先给一只 MOS 管找工作点，再让它接上负载成为放大器。电路会逐步经历差分化、有源负载、偏置、反馈与频率补偿。每次更换结构，都要说明上一版卡在哪里，也要重新检查偏置。增加几只晶体管并不自动意味着升级成功。

主线对应 Razavi 第二版第 2～10 章，文字与图示独立组织。读者需要基本电路分析、复数与微积分知识；不要求预先安装 PDK。

## 已经跑起来的电路

| 版本 | 改动 | 回答的问题 |
|---|---|---|
| V0 | 独立设置 NMOS 四端偏置 | 一个工作点的 gm、gds 与本征增益分别是多少？ |
| V1 | 加入 39 kΩ 漏极电阻与 2 pF 负载，3.3 V 供电 | 漏极电压如何建立？实际增益为何小于 gm·ro？ |
| V1b | 在同一栅极偏置下加入 1 kΩ 源极电阻 | 局部反馈和直流工作点迁移如何同时改变增益？ |

图、CSV 和测量值都由 [实验脚本](../scripts/run.py) 生成。每张数据图都能回到网表和固定版本的 GF180MCU BSIM4 模型；解析近似曲线会单独注明。

阅读时可以先预测参数改变的方向，再看结果。若方向猜错，优先检查哪项约束被悄悄改了：电压、电流、负载、尺寸，还是可用的输出摆幅。
