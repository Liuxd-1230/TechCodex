    6.4 · 把大摆幅留在上面，下面就快了吗¶

    共源级能把栅压变成漏电流，但漏节点的大反相摆幅让 \(C_{gd}\) 很吃力。上面接一只共栅管，让下面那只管的漏极只需小幅移动，就有可能减小这份输入加载。

    先看局部电流怎样被接走¶

    低频下，下管产生 \(g_{m1}v_g\)。上管从源端看进去的导纳约 \(g_{m2}+g_{mb2}\)；当上管漏端没有近乎自由地跟着源端移动时，X 无须很大电压就能传递这份电流：

    \[ \frac{v_x}{v_g}\approx-\frac{g_{m1}}{g_{m2}+g_{mb2}}. \]

    两管跨导同量级时，这个局部增益约为 −1，而不是总输出可能达到的几十或几百。于是输入端对 \(C_{gd1}\) 的低频加载约为

    \[ C_{gd1}\left(1+\frac{g_{m1}}{g_{m2}+g_{mb2}}\right), \]

    比单管高增益共源的米勒项小得多。这里的近似先忽略 \(g_o\)，并假定上管偏置足够固定；若输出阻抗极大、\(g_o\) 耦合重要，就需要下面的完整方程。

    X 没有消失，它有自己的电荷¶

    X 处包含下管漏结电容、上管栅源与源体电容；上管偏置并不理想时，还要考虑偏置节点本身。粗估 X 节点频率为 \((g_{m2}+g_{mb2})/(2\pi C_X)\)，它通常较高，却可能在减小输出负载后变成速度限制。

    与此同时，共源共栅提高了输出电阻。若输出仍带固定 \(C_L\)，提高电阻会增加低频增益，也会延长输出充放电时间。这正是“改善输入米勒效应”与“提高整个放大器 −3 dB 带宽”不能画等号的原因。

    三节点 KCL：保留 X 与输出的耦合

    令 \(g_1,g_2\) 为下、上管输出电导，\(k_2=g_{m2}+g_{mb2}+g_2\)，\(G_D=1/R_D\)，\(C_f=C_{gd1}\)。\(C_X\) 不含已单列的 \(C_f\)，忽略漏源跨接电容，模型为

    \[ \begin{bmatrix} G_i+s(C_{gs1}+C_f)&-sC_f&0\\ g_{m1}-sC_f&g_1+k_2+s(C_X+C_f)&-g_2\\ 0&-k_2&G_D+g_2+sC_O \end{bmatrix} \begin{bmatrix}v_g\\v_x\\v_o\end{bmatrix} =\begin{bmatrix}G_iv_{in}\\0\\0\end{bmatrix}. \]

    第二行的 \(-g_2v_o\) 很有意义：上管漏端运动会反馈到 X。第三行中，上管源端运动产生的电流由 \(k_2\) 表示。精确极点来自整个三阶行列式，不是将图上三个 RC 各算一次。

    如果输入由理想电压驱动，\(v_g\) 不再是独立动态状态，但 \(C_f\) 的前馈仍进入 X 方程。若输出极点远低于 X 极点，可以先把 X 近似为快速节点，再估算输出主极点；反过来将所有高频路径都压进一个 \(R_{out}C_L\) 会漏掉内部限制。

    同一个拓扑，换限制条件会得到不同答案¶

    上图 \(R_S=10\) kΩ、\(C_L=1\) pF：共源约 4.05 MHz，共源共栅约 3.94 MHz。输入端原本不是主要瓶颈，增加上管结电容与内部节点，不会让大负载自动更快。

    下图 \(R_S=1\) MΩ、\(C_L=0.05\) pF：共源约 3.22 MHz，共源共栅约 4.74 MHz。输入加载变得重要，限制 X 摆幅的优势才显现。这也不是说 4.74 MHz 就是 X 的精确极点，而是指定端口在这组终接下的 −3 dB 带宽。

    设计时应先判断受限位置。若输入米勒项占主要时间常数，共源共栅有明确动机；若输出负载主导，可能更需要跨导、电流、负载或后级缓冲的改变。加宽上管能降低 X 电阻，也会增加 \(C_{gs2},C_{sb2}\) 和相关结电容；堆叠还要消耗电压余量。尺寸应通过这两边的变化选择，不能只追求一个更大的 \(g_m\)。
