    TechCodex¶

    从零开始的模电生活¶

    基于拉扎维《模拟 CMOS 集成电路设计》第二版的理解、推导与实验笔记。

    从一只 MOS 管的电场与电荷出发，沿着电流路径和端口关系，逐步理解放大、加载、偏置与电路设计的取舍。公式用于解答问题，原理图标明节点如何响应，真实工艺实验留在需要检验判断的位置。

    打开在线阅读站 · 在 GitHub 阅读 · 从源跟随器样章开始

    教材、暗线与实验¶

    教材知识负责系统解释器件和各类重要拓扑；电路演化把这些方法串起来；实验用于检验或修正某个判断。它们有不同的任务，阅读时不必先安装工艺模型。

    已有 Windows 原生 ngspice + GF180MCU 实验、原始 CSV、模型哈希与生成脚本完整保留在 实验资源。第二版的组织方法与旧版对照见 编辑说明。

    我要运行仿真或构建网站

    仿真在 Windows PowerShell 中从仓库根目录运行：

    python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/bootstrap.py
.\.venv\Scripts\python.exe scripts/run.py --check
.\.venv\Scripts\python.exe scripts/check_repo.py

    无需 WSL、容器或完整的版图工具链。配置、模型与实际验证范围见 Windows 复现 和 模型说明。网站单独使用 .venv-site，见 构建与发布。

    TechCodex 以后也会收录数字电路、Python、PCB、Git、电力电子等技术笔记，模拟系列保存在独立的 模拟/ 目录。原创文字、代码和自绘图采用 MIT 许可；GF180MCU 模型与 MathJax 保留各自 Apache-2.0 许可。未包含教材原图或商业工艺文件。
