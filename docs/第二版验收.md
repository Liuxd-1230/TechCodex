# 第二版验收与样章对照

本轮范围：先完成第 3 章源跟随器教学样章，再重构第 2、3 章与在线阅读站。第 4～10 章仍未成稿。本记录是编辑与技术检查，不是读者学习效果研究。

## 教学自检

| 检查问题 | 第二版对应内容 |
|---|---|
| 读者先知道要解决什么吗？ | 样章从高阻前级被负载拉动进入，先说明缓冲的用途，再计算增益 |
| 公式是否跟随电路变化出现？ | 从 VGS=VI−VO、输出电流平衡到受控源测试，再转换为戴维南等效 |
| 一个方法能否迁移？ | 同样的源端测试连接到共栅输入阻抗；源极退化连接到共源共栅输出电阻 |
| 近似的失效条件是否可见？ | 共栅 Rin 随漏端负载变化；共源共栅高阻抗未必改善低阻负载增益 |
| 正文是否又被实验支配？ | 保留一个真实 CS 加载反例；完整参数、CSV、误差和频响放入实验档案 |
| 知识体系是否拓宽？ | 第 2 章补入结构、电荷积分、二阶效应和电容；第 3 章覆盖主要单级拓扑及负载形式 |

旧版保留在 [器件档案](../模拟/实验/首版器件笔记.md)、[共源级档案](../模拟/实验/首版共源级笔记.md) 和 Git 历史中。新版不能仅因排版更好就视为教学改善；本次自评依据的是新增解释链、端口方法与可迁移的反例，尚无独立读者测试。

## 数学与图示核查

样章解析例子的输出电阻与三个加载增益已核对。使用独立的 MOS 节点导纳盖章法，对源跟随器、共栅、源极退化和共源共栅公式作代数交叉检查，脚本是 [check_teaching.py](../scripts/check_teaching.py)。这些解析检查不冒充工艺仿真数据。

原理图使用明确区分 D/G/S/B 的四端符号、体结箭头及独立体连接；青色箭头只表示扰动。器件截面与电容图为概念图，标明未按真实工艺比例绘制、不能替代完整 BSIM 电荷模型。图源保存在 [生成脚本](../scripts/draw_schematics.py) 与 [矢量绘图模块](../scripts/circuit_art.py)。
